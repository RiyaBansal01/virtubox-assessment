Virtubox Assessment

A professional full-stack project management web application built using:

- Node.js
- Express.js
- SQLite
- EJS
- CSS

## Features

### Authentication
- Signup/Login
- Role-based access (Admin / Member)

### Project Management
- Create projects
- Manage project descriptions
- Track active projects

### Task Management
- Create tasks
- Assign tasks to members
- Status tracking
- Priority management
- Due dates

### Dashboard
- Analytics cards
- Overdue tracking
- Recent projects
- Recent tasks

### UI
- Responsive SaaS-style dashboard
- Modern cards
- Professional layout

## Tech Stack

- Node.js
- Express.js
- SQLite
- EJS
- CSS

## Installation

```bash
npm install
node server.js
```

Open:

```bash
http://localhost:3000
```
